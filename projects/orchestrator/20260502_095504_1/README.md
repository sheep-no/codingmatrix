# Two Numbers Adder

## 项目简介
本项目实现了一个核心功能：计算两个数的和。提供 `add.py` 文件中的核心函数实现，以及 `test_add.py` 中的单元测试用例，适用于简单的数值加法场景。

## 功能描述
### 核心函数
`add.py` 中的 `add` 函数接收两个参数，返回它们的和。函数支持以下类型：
- 整数（int）
- 浮点数（float）
- 其他可相加的类型（如复数、字符串等）

函数包含以下特性：
1. 类型注解以确保参数类型安全
2. 基础错误处理（如非数字输入）
3. 简洁的实现逻辑

### 单元测试
`test_add.py` 包含以下测试用例：
- 正确的数值加法
- 边界值测试（如零、负数）
- 类型兼容性测试
- 异常处理测试（如非数字输入）
