# 文件上传任务指南

## 概述

基于任务队列的文件上传方案，适合超大文件和需要后台处理的场景。

## 使用场景

- 超过 100MB 的大文件
- 需要病毒扫描的文件
- 需要格式转换的文件
- 需要提取元数据的文件

## API 流程

1. 创建上传任务: `POST /api/v1/tasks`
2. 上传文件数据 (通过任务关联)
3. 查询状态: `GET /api/v1/tasks/{task_id}`
4. 获取结果: 任务完成后返回文件 ID

## 任务状态

| 状态 | 描述 |
|------|------|
| pending | 等待处理 |
| uploading | 上传中 |
| processing | 处理中 |
| completed | 完成 |
| failed | 失败 |
| cancelled | 已取消 |
