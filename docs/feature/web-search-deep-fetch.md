# 深度搜索功能

## 概述

深度搜索在基础网络搜索之上，增加了 LLM 摘要和多层递归搜索能力。

## 工作流程

```
用户查询 -> 初始搜索 -> LLM 分析结果 -> 发现新关键词
    -> 二次搜索 -> LLM 综合分析 -> 最终回答
```

## 特点

- **递归搜索**: 根据初步结果自动扩展关键词
- **LLM 摘要**: 每次搜索结果由 LLM 提取关键信息
- **综合报告**: 最终输出结构化分析报告

## API 使用

通过 Agent 模块间接使用:

```
POST /api/v1/agent/process
{"task": "research", "query": "深度学习最新进展", "depth": 3}
```

## 配置

```env
SEARCH_DEPTH=2           # 递归深度
SEARCH_MAX_PAGES=20      # 最大搜索页数
SEARCH_SUMMARY_MODEL=qwen2.5-72b  # 摘要模型
```

## 与基础搜索的区别

| 特性 | 基础搜索 | 深度搜索 |
|------|----------|----------|
| 搜索次数 | 1 次 | 多次 (2-5 次) |
| 结果处理 | 直接返回 | LLM 摘要 |
| 响应时间 | < 5s | 10-60s |
| 适用场景 | 简单查询 | 深度调研 |
