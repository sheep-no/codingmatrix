## 文档维护

- 每次版本发布时，在 `versions/` 目录下创建新的 CHANGELOG 文件
- 命名格式：`CHANGELOG-vX.Y.Z.md`
- 重大版本（X 变化）额外创建总结报告：`VX.Y.Z-SUMMARY.md`
- 专项报告按需创建
