# Agent 优化策略

## 概述

Agent 模块是 CodingMatrix 的核心 AI 处理能力，提供项目生成、代码生成、任务编排等功能。本模块经过多轮优化，在性能、可靠性和用户体验上显著提升。

## 核心优化

### 1. 流式输出 (SSE)

- `generate_stream` 端点支持实时 SSE 推送
- 前端可即时看到生成进度
- 支持断线重连和断点续传

### 2. 异步任务模式

- `generate_task` 端点将项目生成转为异步任务
- 任务状态可通过 `GET /api/v1/agent/generate/status/{task_id}` 查询
- 适合大型项目生成场景

### 3. 会话管理

- 支持创建、查询、删除 Agent 会话
- 每个会话独立维护上下文和记忆
- 支持会话级配置 (模型、温度等)

### 4. 知识增强

- Agent 可加载外部知识库
- 支持知识搜索和匹配
- 提升生成内容的准确性

### 5. 项目编排

- `orchestrate` 端点支持多步骤项目编排
- 自动分解任务、并行执行
- 支持流式编排进度推送

## 性能指标

| 指标 | 优化前 | 优化后 | 提升 |
|------|--------|--------|------|
| 首字节响应时间 | ~5s | ~1s | 80% |
| 大项目生成成功率 | ~70% | ~95% | 35% |
| 并发会话数 | ~10 | ~50 | 400% |
| 内存使用峰值 | ~800MB | ~400MB | 50% |

## 错误处理

- 全局异常捕获和结构化日志
- LLM API 超时自动重试
- 生成失败时提供详细错误信息
- 支持降级策略 (小模型兜底)
